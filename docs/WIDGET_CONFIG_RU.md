# Настройка пресетов виджета

Файл `widget-config.json` хранится в пользовательской папке данных ARC Live. Его
можно открыть кнопкой **Виджет OBS → Открыть файл пресетов**. Рядом есть кнопка
**Перезагрузить пресеты** — она перечитывает файл сразу, без перезапуска
приложения и без новой синхронизации с игрой. Файл также перечитывается при
каждом обновлении статистики.

## Структура

```json
{
  "schema_version": 2,
  "presets": [
    {
      "id": "pve",
      "name_ru": "PvE · лут и ARC",
      "name_en": "PvE · loot and ARC",
      "cells": [
        {
          "source": "session.loot_value",
          "add": [],
          "subtract": [],
          "label_ru": "Вынесено за стрим",
          "label_en": "Stream loot",
          "style": "loot"
        }
      ]
    }
  ]
}
```

Пресет:

- `id` — латиница, цифры и дефис. Используется в приложении и в OBS
  (`?preset=<id>`). Должен быть уникальным.
- `name_ru` и `name_en` — имя пресета в списке приложения.
- `cells` — от 1 до 4 показателей. Сколько показателей, столько колонок в
  виджете.

Показатель:

- `source` — основной источник значения;
- `add` — источники, которые прибавляются;
- `subtract` — источники, которые вычитаются;
- `label_ru` и `label_en` — подписи под числом;
- `style` — оформление: `plain` (белый), `accent` (зелёный), `danger`
  (красный), `loot` (жёлтый), `balance` (знак `+`/`−` и цвет по знаку).

Пресетов может быть до 12. Порядок в файле — это и порядок в списке приложения,
и нумерация для `?preset=1`, `?preset=2` и так далее.

## Источники значений

Именованные источники: `account.loot_value`, `account.raider_damage`,
`account.xp_gained`, `session.extractions`, `session.loot_value`,
`session.money_delta`, `outcome.wins`, `outcome.losses`, `today.extractions`
и другие поля из ответа игры.

Любой числовой агрегат можно выбрать по идентификаторам события:

- `account.event.101` — сумма события 101 по всем целям;
- `account.event.101.target.995408715` — событие 101 только для указанной цели;
- `session.event.200.target.995408715` — изменение показателя за текущий стрим;
- `today.event.9801` — значение за сегодня, если игра отдаёт дневной scope.

Полный актуальный каталог ключей есть в локальном JSON
`http://127.0.0.1:17842/api/v1/overlay` (или по фактическому адресу из
приложения, если порт был занят) в полях `raw_totals`, `session_raw_totals` и
`today_raw_totals`. Там только числовые идентификаторы и агрегаты; токены и
сырые ответы игры туда не попадают.

## Добавить свой пресет

Скопируйте любой блок из `presets`, поменяйте `id`, имена, набор `cells` — и
нажмите **Перезагрузить пресеты**. Новый пресет сразу появится в списке
приложения и станет доступен в OBS по своему `id`.

Если JSON повреждён или не проходит проверку, ARC Live продолжает работать на
последнем корректном наборе пресетов и показывает причину на экране
**Виджет OBS**. После исправления файла нажмите **Перезагрузить пресеты**.

## Миграция со старого формата

Файлы версии 1 (`account`, `session`, `outcome`, `pve`, `pvp` фиксированного
размера) конвертируются автоматически при первом запуске: получаются те же пять
пресетов с сохранением ваших источников и подписей. Старый файл переписывается
новым форматом.
