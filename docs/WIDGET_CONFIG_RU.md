# Настройка данных виджета

Файл `widget-config.json` хранится в пользовательской папке данных ARC Live. Его
можно открыть через **Настройки → Файлы и восстановление**. ARC Live перечитывает
его при каждой синхронизации статистики, поэтому для изменения источника данных
не нужно пересобирать или заменять EXE.

Каждый показатель содержит:

- `source` — источник значения;
- `subtract` — источники, которые нужно вычесть;
- `label_ru` и `label_en` — подписи виджета.

Доступны именованные источники, например `account.loot_value`,
`session.extractions`, `session.money_delta`, `outcome.wins` и
`outcome.losses`.

ARC Live также получает все числовые строки статистики. Их можно выбрать по
идентификаторам:

- `account.event.101` — сумма события 101 по всем целям;
- `account.event.101.target.995408715` — событие 101 только для указанной цели;
- `session.event.200.target.995408715` — изменение такого показателя за стрим;
- `today.event.9801` — значение события за сегодня, если игра предоставляет
  дневной scope.

Полный актуальный каталог ключей и значений доступен в локальном JSON
`http://127.0.0.1:17842/api/v1/overlay` в полях `raw_totals`,
`session_raw_totals` и `today_raw_totals`. Эти данные состоят только из числовых
идентификаторов и агрегатов; токен и сырые ответы игры туда не попадают.

Если JSON повреждён, ARC Live оставляет последнее рабочее сопоставление и пишет
ошибку во внутренний журнал. После исправления файла новое правило применится
при следующей синхронизации.
