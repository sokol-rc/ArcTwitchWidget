# Готовность ARC Live к распространению

## Вердикт

Текущая реализация не готова к публичному распространению и не должна
использоваться на основных игровых аккаунтах без письменного разрешения
Embark. Она пассивно расшифровывает TLS-трафик игры и читает ответ внутренней
ручки `POST /v1/pioneer/stats/player-v2`. Начиная с разработки 0.11 активный replay
удалён: приложение не извлекает bearer-токен и не отправляет собственные запросы,
а один раз обрабатывает штатный ответ самой игры при возвращении в Сперанцу.
Ручка по-прежнему не является документированным публичным API.

Действующие пользовательские условия запрещают перехват протоколов, packet
sniffing, data mining и создание неразрешённых подключений к сервисам. Политика
банов также предупреждает, что внешнее ПО, взаимодействующее с игрой, может
вызвать anti-cheat-санкции:

- https://m.nexon.com/terms/825
- https://id.embark.games/arc-raiders/support/faq/161-ban-and-enforcement-policy
- https://id.embark.games/arc-raiders/support/faq/167-common-anti-cheat-questions

## Какие запросы выполняет ARC Live

ARC Live не выполняет собственных запросов к Embark. Она пассивно наблюдает
штатный запрос игры:

- `POST https://api-gateway.<регион>.es-pio.net/v1/pioneer/stats/player-v2`;
- региональный host определяется автоматически по TLS SNI и HTTP Host игры;
- ответ обрабатывается один раз, когда его получает сама игра;
- таймера, retry, копирования авторизации и дополнительной нагрузки на API нет.

Остальные пути Embark в диагностике — пассивно замеченный трафик самой игры.
ARC Live их не вызывает. В старых проверенных сессиях 76 активных запросов
предыдущей реализации возвращали HTTP 200; эта реализация удалена. Единичные
HTTP 403 и 404 относились к запросам самой игры к social-party/auth ручкам.

## Технические блокеры массовой установки

- Поддерживается только Windows x64.
- Нужны права администратора для установки LocalSystem-сервиса и драйвера
  WinDivert.
- EXE/MSI не имеют коммерческой Authenticode-подписи, поэтому SmartScreen может
  блокировать или настораживать пользователя.
- Если Steam или Epic уже запущен без `SSLKEYLOGFILE`, первая установка не может
  подключиться мгновенно: переменная начнёт действовать только после следующего
  обычного запуска лаунчера.
- Реально проверен только один Steam/Embark-аккаунт. Epic Games Launcher и
  другие аккаунты не прошли живой тест.
- Региональные `api-gateway.<регион>.es-pio.net` определяются динамически, но
  живой тест Asia/Automatic ещё требуется.
- Захват ограничен IPv4; соединение игры по IPv6 будет пропущено.
- Идентификаторы категорий целей `995408715` и `200993951` получены
  экспериментально и не подтверждены на втором аккаунте.
- Web UI, capture-service и активация второго экземпляра выбирают свободные
  loopback-порты при конфликте. Сервис обслуживает одного подключённого GUI за
  раз, поэтому одновременные Windows-пользователи не поддерживаются.
- Автоматические интеграционные тесты на чистой Windows VM, Steam и Epic
  отсутствуют.

## Условия для публичного релиза

1. Получить письменное разрешение Embark и документированный API либо перейти
   на источник данных, не требующий перехвата трафика и игровых credentials.
2. Активный replay уже удалён. Следующий шаг — минимизировать пассивный захват до
   соединений ARC Raiders и получить подтверждение допустимости такого оверлея.
3. Проверить минимум два независимых Steam-аккаунта, Epic, IPv4/IPv6 и разные
   регионы на чистых Windows 10/11 VM.
4. Провести живой raid-тест событийного обновления и подтвердить, что один
   штатный ответ `player-v2` приходит после каждого возвращения в Сперанцу.
5. Подписать установщик Authenticode и провести независимый security review
   LocalSystem-сервиса, обновлений и локального API.
